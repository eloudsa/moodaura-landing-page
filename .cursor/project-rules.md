# Project Rules for moodaura-landing-page

- [ ] Use semantic HTML5 elements for all new or updated pages.
- [ ] All images must have descriptive `alt` attributes for accessibility.
- [ ] Place all assets (images, icons, legal docs) in the correct subfolders under `assets/`.
- [ ] Keep legal pages (`privacy.html`, `terms.html`, etc.) up to date and linked from every page.
- [ ] Use external CSS and JS files; avoid inline styles/scripts unless necessary.
- [ ] Do not commit personal or system files (e.g., `.DS_Store`).
- [ ] Write clear, descriptive commit messages.
- [ ] Update `README.md` with any major changes or new dependencies.
- [ ] Ensure all new content meets accessibility standards (WCAG AA).
- [ ] Optimize images before adding them to the repository.
