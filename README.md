# MoodAura Web Landing Page

This repository contains the source code for the **MoodAura** web landing page — the official site that introduces users to the MoodAura mobile app. MoodAura is a thoughtfully designed tool to help individuals track, understand, and reflect on their emotional well-being.

The landing page presents the app’s purpose, highlights key features, and offers download links for both Android and iOS platforms.

---

## About MoodAura

**MoodAura** is a cross-platform emotional tracking app that empowers users to develop greater self-awareness through mood logging, visual analytics, and journaling.

Whether you're seeking to understand your emotional patterns, reflect on your daily experiences, or generate insightful reports, MoodAura supports your emotional journey with elegance and privacy-first technology.

Key features include:

- **Mood Tracking**: Record mood, intensity, activities, location, and notes throughout the day.
- **Visual Timeline**: Explore your emotional patterns using a matrix and timeline view based on the Circumplex Model of Affect.
- **Journaling**: Capture context-rich reflections and search them easily.
- **Analytics & Reports**: View trends and generate shareable PDF summaries.
- **Privacy by Design**: Offline-first architecture with optional secure cloud sync.
